# Sharp Group Website

A responsive multi-section company website for Sharp Group, a digital agency, built with HTML and CSS during my programming internship.

**Live demo:** https://albenisahamidi.github.io/sharp-group/

## Sections
- Header with navigation and dropdown menu
- Hero section with call-to-action
- Statistics bar
- Services cards
- Management team
- Client testimonials
- Contact form and office locations
- Footer with social links

## Built with
HTML5, CSS3 (Flexbox, media queries)
